# Handoff documents

Every session/project handoff lives in this folder, dated in its filename:

    YYYY-MM-DD_<topic>_handoff.md

The date is the day the handoff was written (for pre-convention documents, the
original git creation date). Do not rename or rewrite historical handoffs;
supersede them with a new dated document that links back.

## Reading and writing

- **Start of every session:** read the last three entries of the index below
  (newest last), then recheck their cluster facts before acting.
- **End of every session:** add a new dated handoff and append it to the index.
  The index order is authoritative when several handoffs share a date.
- Suggested sections: code state (branch, pins, tests), operator pages,
  cluster facts, what ran and its results, decisions, next actions in order.
