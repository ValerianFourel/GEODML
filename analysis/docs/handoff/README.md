# Handoff documents

Every session/project handoff lives in this folder, dated in its filename:

    YYYY-MM-DD_<topic>_handoff.md

The date is the day the handoff was written (for pre-convention documents, the
original git creation date). Do not rename or rewrite historical handoffs;
supersede them with a new dated document that links back.
