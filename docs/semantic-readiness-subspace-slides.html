2coordinates summarize different semantic changes
Axis 1 · dominant

How close is the request to action?

It carries almost all of the scalar readiness direction: abstract inquiry → evaluation → commitment → action.

Axis 2 · secondary

What kind of readiness is it?

It is nearly orthogonal to the scalar score: comparing or selecting → executing or implementing.

“Two axes” means a useful, reproducible 2D supervised summary—not proof that human intent has exactly two dimensions.rubric component share · 0.71–0.75
